# Bản đồ docs

- `WORKFLOW.md` — cách chọn hình thức việc, các luồng việc, chuẩn hoàn tất.
  Đọc đầu tiên sau `AGENTS.md`.
- `plans/` — việc bền vững nhiều session.
  - `plans/active/` — plan đang làm (1 việc = 1 file).
  - `plans/completed/` — plan đã xong + verify.
  - `plans/README.md` — quy ước khi nào cần plan.
- `decisions/` — biên bản quyết định kiến trúc (ADR đánh số).
- `templates/` — mẫu `exec-plan.md` và `decision.md`.
- `patterns/encoding-invariants.md` — pattern mã hóa invariant thành check
  cơ học.
- `pairing-mattpocock.md` — bảng ghép skill mattpocock vào khung.
